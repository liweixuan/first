# specs/ —— 当前现实（Source of Truth）

本目录保存项目的**当前现实**规格，是所有能力/模块的权威描述。

## 规则

1. **只读于日常开发**：开发过程中不直接编辑本目录；
   现实只在变更归档（archive）时通过 delta 合并更新。
2. **按能力分文件**：每个能力一个 spec 文件，如 `auth.md`、`export.md`，
   文件名即能力名，使用 kebab-case。
3. **规格格式**：每个文件由 `## Requirements` 组织，
   每条需求使用 `### Requirement: <名称>` + `#### Scenario: <场景>` 结构。
4. **查询优先**：代理在任何开发动作前，先查询本目录中相关能力的当前规格，
   避免基于过期认知做决策。
