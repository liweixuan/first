## Purpose
前端工程骨架能力：定义 Vue 3 前端的基础行为契约，包括首页渲染、经代理连通后端、HTTP 客户端统一错误处理与状态管理，作为后续页面开发的公共地基。

## ADDED Requirements

### Requirement: 首页渲染
应用 MUST 在根路径渲染出可用的首页布局，包含导航与内容区域。

#### Scenario: 访问根路径
- **WHEN** 用户在浏览器打开前端应用的根路径
- **THEN** 页面渲染成功，导航区与内容区可见

### Requirement: 后端连通
开发环境下前端 MUST 能经代理访问后端接口，并在页面上展示后端返回的数据。

#### Scenario: 页面展示后端分页数据
- **WHEN** 用户打开示例资源列表页面，后端服务正常运行
- **THEN** 页面展示来自后端的示例资源列表与总记录数

#### Scenario: 后端不可用时的表现
- **WHEN** 后端服务未启动，用户打开示例资源列表页面
- **THEN** 页面展示统一的错误提示，而非白屏或未捕获异常

### Requirement: HTTP 客户端统一错误处理
所有通过 HTTP 客户端发起的请求 MUST 经过统一响应处理，业务错误与非 200 响应统一转为可展示的错误信息。

#### Scenario: 业务错误码提示
- **WHEN** 后端返回统一信封且 `code` 非 0
- **THEN** 页面弹出包含该 `message` 的错误提示，且请求方收到 rejected 的 Promise

#### Scenario: 网络或服务端异常提示
- **WHEN** 请求返回非 2xx HTTP 状态或网络错误
- **THEN** 页面弹出通用错误提示，且不向用户暴露技术细节

### Requirement: 示例资源状态管理
应用 MUST 使用集中式状态管理保存示例资源列表数据，页面组件从状态中读取数据。

#### Scenario: 列表数据写入状态
- **WHEN** 示例资源查询请求成功
- **THEN** 返回的记录与总数被写入全局状态，列表组件从全局状态渲染数据
